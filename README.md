# 🧬 DNA Sequence Analyzer

My first bioinformatics project, built using Python.

## Features

* DNA sequence length calculation
* Nucleotide counting (A, T, G, C)
* GC content calculation
* DNA to RNA transcription
* Reverse complement generation
* Automatic results report

## Technologies

* Python 3

## How to Run

1. Install Python 3.
2. Download this repository.
3. Open a terminal in the project folder.
4. Run `python dna_analyzer.py`.
5. Enter a DNA sequence when prompted.

## Example

Input: `ATGCGATCGATCGATCG`

## Purpose

This project helped me explore Python programming and basic DNA sequence analysis.
