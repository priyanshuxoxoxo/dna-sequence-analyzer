# 🧬 DNA Sequence Analyzer

A beginner bioinformatics project built with Python to explore DNA sequence analysis, FASTA file processing, motif searching, and scientific visualization.

## 🚀 Features

- **DNA Sequence Analysis:** Calculate sequence length, nucleotide counts, GC content, RNA sequence, and reverse complement.
- **FASTA Analysis:** Read and analyze multiple DNA sequences from a FASTA file.
- **DNA Visualization:** Generate bar charts showing nucleotide composition.
- **GC Content Comparison:** Calculate and visualize GC percentages across multiple sequences.
- **Sequence Validation:** Check whether a DNA sequence contains only valid A, T, G, and C bases.
- **Motif Finder:** Search for DNA patterns and report their positions.
- **DNA Analysis Toolkit:** Access multiple analysis functions through an interactive menu.

## 🛠️ Technologies Used

- Python
- Matplotlib
- FASTA file format
- Basic computational biology
